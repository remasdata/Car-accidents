# Car-accidents
Data mining and analysis of traffic accident data to identify patterns, trends, and contributing factors.
This project aims to analyze car accident data to detect patterns and factors affecting accidents, by cleaning and processing the data, performing exploratory and imaging analysis to understand the distribution of accidents by time and location in order to support the understanding of the causes of accidents and contribute to improving traffic safety.

Assessed data quality across multiple dimensions including accuracy, completeness, consistency, validity, and timeliness.

Performed exploratory data analysis (EDA) to uncover patterns and relationships influencing accident severity.

Handled missing data using KNN imputation techniques.

Built and evaluated a Decision Tree classification model to predict accident severity.

Extracted actionable insights to support road safety and responsible authorities.
